# Support

**yache-local-voice** is a community plugin for Hermes Agent. There is no paid support
channel — but there are three good ways to get help:

1. **Read first:** the [README](README.md) (install steps, CUDA pack guide, voice setup) and the changelog.
2. **Ask:** [Discussions -> Q&A](https://github.com/LuuMoss/yache-local-voice/discussions/categories/q-a)
   — install trouble, model/engine setup, "why is it slow" questions all live
   here. Threads can be marked answered and become searchable knowledge.
3. **Report a bug:** use the
   [bug report form](https://github.com/LuuMoss/yache-local-voice/issues/new/choose).
   Please attach the tail of the log file
   (`<HERMES_HOME>/plugin-data/yache-local-voice/`) — most issues are diagnosed from
   the log alone.

Please keep personal or private data (API keys, private file paths,
voice recordings) out of public threads; use the private channel from
`SECURITY.md` for anything sensitive.
